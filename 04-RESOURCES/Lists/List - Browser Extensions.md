> [!info] About
> Curated, browser-extensions list I use currently, have used in the past, or consider relevant. Most are Chromium extensions that work in both Microsoft Edge and Google Chrome; items exclusive to a browser are flagged inline. Extensions are split into **Active**, **Installed (Inactive)**, and **Archived**. Active items link to their own tool note; the rest link to their store / repo / homepage. Per-extension details and use cases live in each extension's own note.

> *These are my currently installed and activated **core** extensions and are kept enabled across browser profiles for consistent use.*

## Installed (Inactive)

> [!NOTE]
> *Extensions present in one or more profiles but not part of my active set, grouped by use case.*

### AI Chat Export and Notes

- [Claude](https://microsoftedge.microsoft.com/addons/detail/fcoeoabgfenejglbffodgkkbkcdhcgfn): Anthropic Claude companion extension.
- [Claude to Obsidian](https://microsoftedge.microsoft.com/addons/detail/ehacefdknbaacgjcikcpkogkocemcdil): Export Claude conversations to Markdown/Obsidian.
- [Save my Chatbot](https://microsoftedge.microsoft.com/addons/detail/agklnagmfeooogcppjccdnoallkhgkod): Export AI conversations (ChatGPT/Claude/etc.) to Markdown.
- [Perplexity to Obsidian](https://microsoftedge.microsoft.com/addons/detail/afmlkbanimddphcomahlfbaandfphjfk): Batch-export Perplexity threads to the vault.
- [Save ChatGPT to Obsidian](https://chromewebstore.google.com/detail/bdkpamdmcgamabdeaeehfmaiaejcdfko): Save ChatGPT chats as Markdown files.
- [Obsidian ChatGPT Notes](https://microsoftedge.microsoft.com/addons/detail/jimnilibkolndnahjjhcklhgonngkhhg): ChatGPT → Obsidian notes integration.

### Markdown Web Clipping

- [MarkDownload](https://microsoftedge.microsoft.com/addons/detail/pcmpcfapbekmbjjkdalcgopdkipoggdi): Save pages as Markdown (with front-matter templating). ([repo](https://github.com/deathau/markdownload))
- [MarkSnip](https://chromewebstore.google.com/detail/kcbaglhfgbkjdnpeokaamjjkddempipm): Webpage → Markdown clipper (MarkDownload successor/fork).

### Developer Tools

- [Demystify](https://chromewebstore.google.com/detail/kndebpfokhpnobjefobnfcidacfannii): Generate OpenAPI specs from observed network traffic.
- [OpenAPI DevTools](https://github.com/AndrewWalsh/openapi-devtools): Generate OpenAPI specs from observed network traffic.
- [WebSocket DevTools](https://chromewebstore.google.com/detail/fmnaobbfmjaaaebelkacpmmmpaaefbod): Inspect and debug WebSocket frames.
- [React Developer Tools](https://chromewebstore.google.com/detail/fmkadmapgofadopljbjfkapdkoienihi): Inspect React component trees.
- [CSS Peeper](https://chromewebstore.google.com/detail/mbnbehikldjhnfehhnaidhjhoofhpehk): Inspect styles, fonts, and colors on a page.
- [Tampermonkey](https://www.tampermonkey.net/): Userscript manager.
- [Snippets](https://chromewebstore.google.com/detail/fakjeijchchmicjllnabpdkclfkpbiag): Reusable code/text snippets.
- [GitKraken](https://chromewebstore.google.com/detail/egmopflbpgdjmmkeabegohajillnebco): GitKraken browser integration (GitHub/GitLab enhancements).
- [Vercel](https://chromewebstore.google.com/detail/lahhiofdgnbcgmemekkmjnpifojdaelb): Vercel deploy/preview integration.
- [Microsoft Edge DevTools Enhancements](https://microsoftedge.microsoft.com/addons/detail/kfbdpdaobnofkbopebjglnaadopfikhh): DevTools add-ons. *(Edge only)*
- [Microsoft Edge Unminification Extension](https://microsoftedge.microsoft.com/addons/detail/cgjgjfacjflmgphhhepmbhhbgjieaecn): Auto-unminify sources in DevTools. *(Edge only)*

### Bookmarks & Read-Later

- [LazyCat Bookmark Cleaner](https://chromewebstore.google.com/detail/aeehapalakdoclgmfeondmephgiandef): Find and clean dead/duplicate bookmarks.
- [Bookmarks Backuper](https://chromewebstore.google.com/detail/jdcbhaadjnkcdklbjkmgbpjaoonekpjd): Periodic export/backup of bookmarks.
- [Readwise Highlighter](https://chromewebstore.google.com/detail/jjhefcfhmnkfeepcpnilbbkaadhngkbi): Highlight and save to Readwise.

### Tabs & Sessions

- [Tab Copy](https://chromewebstore.google.com/detail/micdllihgoppmejpecmkilggmaagfdmb): Copy tab/window URLs in bulk to various formats (Markdown, links, etc.).

### Time Tracking

- [Toggl Track](https://chromewebstore.google.com/detail/oejgccbfbmkkpaidnkphaiaecficdnfn): Time tracking integrated into web apps.

### Reading & Accessibility

- [Dark Reader](https://darkreader.org/): Dark mode for all sites.
- [Edge relevant text changes](https://microsoftedge.microsoft.com/addons/detail/jmjflgjpcpepeafmmgdpfkogkghcpiha): Highlights relevant text. *(Edge only)*

### Ecosystem Integration

- [Google Docs Offline](https://chromewebstore.google.com/detail/ghbmnnjooekpmoecnnnilnnbdlolhkhi): Offline access to Google Docs/Sheets/Slides.
- [Application Launcher for Drive](https://chromewebstore.google.com/detail/lmjegmlicamnimmfhcmpkclmigmmcbeh): Open Drive files with desktop/web apps.
- [Record Transcribe for Google Meet](https://chromewebstore.google.com/detail/lknmjhcajhfbbglglccadlfdjbaiifig): Record/transcribe Meet calls.
- [Adobe Acrobat](https://microsoftedge.microsoft.com/addons/detail/elhekieabhbkpmcefcoobjddigjcaadp): PDF edit/convert/sign tools.
- [Microsoft Bing Search](https://chromewebstore.google.com/detail/hkecabaloghleaicfhefejdijblljpco): Bing search integration. *(Chrome only)*

### Personal

- [AwardWallet](https://chromewebstore.google.com/detail/lppkddfmnlpjbojooindbmcokchjgbib): Track travel rewards / loyalty points.
