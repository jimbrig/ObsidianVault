> Curated, browser-extensions list I use currently, have used in the past, or consider relevant. Most are Chromium extensions that work in both Microsoft Edge and Google Chrome; items exclusive to a browser are flagged inline. Active extensions (and a few others) link to their own tool note; the rest link to their store / repo / homepage. Per-extension details and use cases live in each extension's own note.

## Relevant Extensions by Category

Below are extensions grouped by their respective categories and use cases. Items with a dedicated tool note are wiki-linked; the rest link to their Chrome Web Store / Edge Add-ons / repo page.

### Passwords & Security

- [Tab Copy](https://chromewebstore.google.com/detail/micdllihgoppmejpecmkilggmaagfdmb) — Copy tab/window URLs in bulk to various formats (Markdown, links, etc.).

### New Tab & Dashboard

- [[Momentum]] — Replacement new-tab dashboard (focus, todo, weather).

### Bookmarks & Read-Later

- [[Raindrop]] — Cross-browser bookmark manager and read-later, primary "save" target.

- [Bookmarks Backuper](https://chromewebstore.google.com/detail/jdcbhaadjnkcdklbjkmgbpjaoonekpjd) — Periodic export/backup of bookmarks.

### Tasks & Productivity

- [[Todoist]] — Task capture and planner from the toolbar. *(Edge & Chrome builds have different IDs.)*
- [Toggl Track](https://chromewebstore.google.com/detail/oejgccbfbmkkpaidnkphaiaecficdnfn) — Time tracking integrated into web apps.

- [[Tool - Obsidian Web Clipper|Obsidian Web Clipper]] — Official clipper; primary page → vault capture.

- [Save ChatGPT to Obsidian](https://chromewebstore.google.com/detail/bdkpamdmcgamabdeaeehfmaiaejcdfko) — Save ChatGPT chats as Markdown files.
- [Obsidian ChatGPT Notes](https://microsoftedge.microsoft.com/addons/detail/jimnilibkolndnahjjhcklhgonngkhhg) — ChatGPT → Obsidian notes integration.
