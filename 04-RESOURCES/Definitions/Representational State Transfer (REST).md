## Overview

**Representational State Transfer (REST)** is a set of rules and architectural guidelines used to design web [[Application Programming Interface (API)|APIs]], allowing different computer systems across networks to communicate with each other easily and efficiently.

## How it Works

REST relies on a client-server relationship. Instead of downloading massive amounts of data or complicated code, clients request specific "resources" (like a user profile or a product list) using standard web protocols like [[Hypertext Transfer Protocol (HTTP)|HTTP]].

It uses standard [[Hypertext Transfer Protocol (HTTP)|HTTP]] requests to manage data, matching common actions to specific verbs:

- **`GET`** Retrieve a resource.
- **`POST`** Create a new resource.
- **`PUT`/`PATCH`** Update an existing resource.
- **`DELETE`** Remove a resource
